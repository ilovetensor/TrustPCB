# Sample boards

These boards were designed by the TrustPCB author. The board designs (outline, copper, placement and schematic) are released under the repository's MIT licence for testing and demonstration. The KiCad library footprints, symbols and 3D model references inside them are not: see the licence note below.

| Folder | Board |
|---|---|
| `nrf52840-node` | USB-powered nRF52840 sensor node with a printed meander antenna |
| `nrf52840-node-v2` | The same board after the engineer's hand edits for the free re-tune the review confirmed: L1 becomes a 0.51 pF series capacitor, and C20 and C19 are fitted with 0.3 pF and 0.36 pF. Copper and geometry are unchanged, for version rechecks |
| `nrf52840-node-v3` | A revised nRF52840 node, reviewed in the demo video on Muse Spark Open |
| `patch-2g5` | 2.5 GHz patch antenna on FR-4 |
| `usb-ldo-led` | A 40 x 30 mm USB-C powered 3.3 V regulator board (AP2112K, fuse, CC resistors, status LED, test points) with no radio, for the no-wireless review path |

Symbols, footprints and 3D model references that come from the KiCad libraries (the `.pretty` footprint folders, the `.kicad_sym` symbol files, and the `${KICAD10_3DMODEL_DIR}` model paths in the boards) remain under the KiCad library licence, CC BY-SA 4.0 with the KiCad libraries exception, which does not bind designs that use them. The 3D board model used by the web app's bundled sample (`web/public/fixtures/nrf/`) is built from those same library models and is covered the same way. The first three boards are saved by KiCad 10.

`nrf52840-node-v2` is derived from `nrf52840-node`: only the three edited parts differ, so you can diff the two folders to see the change.

These boards are test material. They are unverified designs and contain real faults, which is why they are useful here. Do not manufacture them as they are.

`usb-ldo-led` has no radio, so a review of it skips the simulation phases. It passes kicad-cli DRC, ERC and the schematic parity check with no violations; its parts, symbols and board were generated by a script, and the board file was then refilled and saved by KiCad 10. It still carries a few small layout faults on purpose, such as input and output capacitors more than 3 mm from the regulator pins and power tracks narrower than their net class asks, so a review has something real to report.
