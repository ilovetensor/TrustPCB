# Phase 6: Report

The server assembles the report from stored findings, evidence and results. Your last job is the summary.

Call `submit_summary` once with a plain-language summary of what you found (what matters most first, what you tested, what you could not test) and up to five top actions for the engineer. Every number with a unit must match the evidence, nothing may say the board was changed, and any finding code you mention must exist. If the summary is rejected, fix the named problem and try again; after three rejections the server writes the summary itself.

After the summary is accepted, stop.
