# Phase 5: Confirm

Goal: make sure a claimed improvement is real. Screen runs are only for comparing; a fix needs a detailed run of both the base and the winner. You have {phase5_calls} tool calls and {confirm_runs} confirm runs in total.

Do this:
1. `confirm_result` with `which` set to `base`, then `winner`, for each investigation that found an improvement.
2. If the confirm run disagrees with the screen run, believe the confirm run and say so.
3. If the improvement does not survive confirmation, update the finding honestly: say it was not confirmed.
4. Update the finding with `record_finding` (use `update` with its code) so its evidence includes the confirm runs. Absolute values may be quoted only from confirm runs with trust ok.

Then call `advance_phase`.
